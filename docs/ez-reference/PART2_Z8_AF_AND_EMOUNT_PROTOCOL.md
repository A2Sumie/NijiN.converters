## 1. Nikon Z8（`v3.10` / `v3.12`）机身对焦与镜头控制软件架构

### 1.1 识别状态机、命令描述符表与 Property Bank

Nikon Z8 机身通过 `SPI3`（两阶段主从全双工事务：8B 请求头 + $N$ 字节数据窗）枚举并管理挂载镜头，核心控制平面由状态机、`164` 条命令描述符与 `600` 项 Property Bank 共同构成：

1. **连接/识别状态机（State `0x00..0x1E`）**：
   - 主控任务（`z8_312_rizin_protocol_sm.txt` 中的 `0x41095e50`、`0x41098f80`、`0x41090e2c`、`0x41090f28`）根据镜头检测引脚、通信握手状态及 `CMD 0x10 / 0x11 / 0x12 / 0x16 / 0x20 / 0x24` 序列推进识别与就绪状态。
   - 在 `0x41090f28` 中，机身读取连接探测状态（参数 `0x18`），异常或断开时将状态寄存器 `0x0A045A23A4` 置入 `0x2D` / `0x15` 退回清理分支；完成验证后将 `0x0A045A23A4` 推进至运行态 **`0x1E`**（并由 `0x41095e50` 触发 `0x410816d0` 事件通知）。
2. **`164` 条命令描述符表（`66` 个唯一命令码）**：
   - 全表定义于 `z8_312_164_descriptors.json`，覆盖 `CMD 0x10..0xFA`，共 `66` 个唯一主命令码、`164` 条 `(cmd, sub)` 描述符（每条记录定长 `0x28` / `0x30` 字节含 `tx_len`、`rx_len`、`tx_fn`、`rx_fn`）。关键控制命令与 `v3.12` 实测处理器 VA 如下：

|---|---:|---|---|---|

3. **Property Bank（`0x000..0x257` 共 `600` 项）与 `0x005` `LF` 版本映射**：
   - 全表共 `600` 项（`z8_312_prop_table.json`，核心接口区覆盖 `0x000..0x246`，尾部至 `0x257`），经 `0x4109e198` / `0x4109ee74` / `0x4109efb4` / `0x4109f418` 按 `w0_bank`、`w3_type`（`Bank 0x0A/0x0B/0x0C/0x0D`）索引读取。
   - **Property `0x005`（`LF` 版本字）**：表项为 `w0_bank=0, m1=(0x1+0x08), m2=(0xB+0x08), fn=0x4109EE74, op=0x2A`。在 `0x410A195C` 中，`CMD 0x10 miso[0x03..0x06]` 分别写入 `Bank 0x0B`（或 `0x01`）偏移 `0x08..0x0B`（即 32-bit `LF` 固件版本字）。`0x41075048` 仅在条件位有效时查询 `prop 0x005` 并写回状态缓存，最高字节 `TX[0x06]` 决定机身及 EXIF 工具软件（`LensData+0x35`）对物距有效性门的识别（[BORYOZA_NEW_FW_DESIGN_SPEC.md](HC32F460_SE_NZ_DESIGN_SPEC.md)）。
   - 其他高频控制 Property：`0x017`（Hotline/通讯标志）、`0x049`（温度读数，消费点 `0x41076274`）、`0x04B` / `0x04C`（释放与能力组，消费点 `0x41083BB0`）、`0x078`（步长/速率上限，消费点 `0x4107B458`/`0x4107B4D0`）、`0x157`（端止模式选择器：值 `3` 走 Hotline 硬件端止，值 `1` 走坐标比较，`0x40DF0838`/`0x40DF08EC`）、`0x246`（扩展校正参数）。

### 1.2 1 kHz `SPI1` Hotline 读取与 AF 状态驱动消费者

Z8 机身通过 `SPI1` 每 `1.000 ms` 接收来自镜头的 `42 B` 连续状态热线包（详见 `BORYOZA` 传输层实现 [z_spi1_hotline.c](../../se-nz/src/01_transport/z_spi1_hotline.c)）：

- **`0x4107A570`（file `0xf1a570`）Hotline 环形摄入与连续性监测**（`z8_hot_clean_fileoff.txt`）：将实时接收帧写入共享结构体 `0x0A045A5960`，以模 `1000`（`cmp w9, 0x3e8; sub w8, w8, 0x3e7`）跟踪帧序并在校验/连续性异常时通过 `mov w0, 0x291; bl 0x40d713d4` 报出通信错误 `0x291`。
- **`0x41078348`（`HOT[6]` bits `[5:4]` -> `event 0x3C` `result_code = 0/1/2`）**：
  1. 当活跃监控标志 `[0x0A045B68A0] == 1` 时，调用 `0x4107A184` 读取最新解码后的 Hotline 状态字（其中 `var_30h` 对应目标状态，`var_54h` 承载 `HOT[6]` bits `[5:4]`）。
  2. 若当前运动模式与期望方向匹配（`[x19+0x198] == var_30h`）：当 `var_54h` 处于 `2..3`（停稳/到达态）时设 `result_code = 2`；否则经 `0x410825dc` 计算得到 `result_code = (~w0) & 1`（即 `0` 或 `1`）。
  3. 若不匹配：递增消抖计数 `[x19+0x199]`，在连续超出阈值（`> 9` 次）时输出 `result_code = 2`。
  4. 最终在 `0x410707c8` 投递内部事件 **`0x3C`**（附带 `result_code = 0 / 1 / 2`）并清零 `[x19]`。
- **`0x4107896C` / `0x410789E0` 回调派发链**：在 `0x410789E0` 调用 `0x4107A184` 核验预期状态（全局状态槽 `0x0A045B6B50..6B60`，消抖 `0x0A045B6B64 > 9`），随后遍历 `0x0A045A57C0` 处 `10` 槽位（`8 B` 步进，共 `0x50 B`）注册回调函数，向各订阅模块传入 `(0x04270110, &status)`，其中 `status = 0` 表示驱动到位停稳、`status = 1` 表示超时/异常中断。

### 1.3 PDAF 离焦换算链路（`K_Z` 解码与线性倍率行为）

机身将像面离焦量 $\Delta d$ 换算为马达目标步长 $\Delta C_Z$ 的核心算子集中在 `0x40DB5200..0x40DB5364`、`0x40DF28CC..0x40DF29A4` 与 `0x40DB76B0`：

1. **灵敏度描述符装配（`0x40DB5200..0x40DB5364` & `0x40DB533C`）**（`z8_kz_hot_cdaf.txt`）：
   - `0x40DB5200` 从镜头属性表读取线性项、对焦敏感度扩展字节（`kz_b0` / `kz_b1`）与标定标志；在 `0x40DB5310` 处执行 `strb wzr, [x19, 0x34]`，当镜头标记不支持非线性查表（如桥接器上报 `CMD 0x12[0x1A..0x1B] = 0x0100`，即 `KZ_NONLIN_DISABLED`）时，清除结构体偏移 `0x34` 处的非线性使能标志，`0x40DB533C` 随后将固定基数装配进 `x0` 输出块供后续算子消费。
2. **`kz_b0 / kz_b1` 解码（`0x40DF28CC..0x40DF29A4`）**（`z8_pupil_cdaf.txt`）：
   - `0x40DF28CC` 提取 `w1[5:0] << 2` 作为主系数，根据 `w0 & 1` 与 `w2` 计算 `0xFE..0xFF` 钳位偏移索引。
   - `0x40DF2904` 与 `0x40DF2920` 采用 `and w9, w8, 0x80; bfi w9, w8, 1, 6` 解包带符号位 7-bit 分段值。
   - `0x40DF293C` 将步进分度代码 `0x0C / 0x12 / 0x18` 映射为挡位 `0x0E / 0x11 / 0x14`（默认 `0x0A`）；`0x40DF2974` / `0x40DF2990` 将哨兵字节 `0xFF` 映射为无效标志 `0xFFFF`（返回 `0`）。
3. **线性与非线性求解器（`0x40DB76B0` / `0x40DB7808` / `0x40DB7864` / `0x40DB7DDC` / `0x40DB7F88`）**（`z8_kz_and_search.txt`）：
   - `0x40DB76B0`（全库 `26` 处直接调用点）在 `KZ_NONLIN_DISABLED` 下直接采用 `0x40DB7808`（右移 `8` 位 `umull >> 8` 有符号饱和缩放）与 `0x40DB7864`（64-bit `smull / sdiv` 饱和除法），在无非线性表干预时按线性倍率精确换算脉冲；而在使能非线性模式时经 `0x40DB7DDC` / `0x40DB7F88` 叠加多段光学表补偿。

### 1.4 AF 搜索（盲搜/限位反转）与合焦确认（转绿）双核心状态机

Z8 机身将“大范围离焦寻峰/端止折返”与“近合焦静稳确认/框转绿”划分为两个耦合状态机，均经 `0x40DCDB2C`（`17` 分支 `w8 <= 0x10` 命令派发器）向镜头下发 `SPI3` 驱动请求：

```text
[PDAF / 搜索派发 0x40DCFA8C]
  ├─> 查端止壁 0x40DF0838 (Far L_Z) & 0x40DF08EC (Near H_Z)
  ├─> 盲搜监控 0x40DD0B40:
  │     ├─ [x21+0x90]==1 || (0x40defc60()|1)==9 || [x22+0x2bc]==2 ─> *sm = 7 (立即放弃)
  │     └─ [0x0A037D1630+0xd] 连续 >= 5 次相同位置 && (t_now - t_start) > 2.0s (0x1E8480 us) ─> bl 0x40dd570c (墙体停滞超时反转)
  └─> 过峰 / 折返切换 0x40DD1FF4 -> 0x40DD1768 (反查端止并调用 CDAF/峰值回退)

[合焦确认 / 转绿状态机 0x40DCBC00]
  ├─> bl 0x40dcba1c 通过 ─> 若 [x19+0x6a94]!=0 && [x21+0x90]==1 && [x19+0x6a8c]!=0 调用 0x40dce078(x20, 0) (恢复微跳 -> 0x40dce154)
  ├─> 写入 *sm = 9, 分发进入 0x40DCBDA4 (case 0..7)
  └─> 确认判据 0x40DCC854:
        └─ w9==1 且 [x19+0x694d] > 4 (>=5)，或 w9==2 且 [x19+0x694e] > 4 ─> 跳 0x40DCC94C 置 *sm = 0x0A (合焦转绿)
```

关键函数机器行为细节（验证源码 `z8_af_core_part1.txt`、`z8_af_core_part2.txt`、`z8_pupil_cdaf.txt`）：

1. **端止壁判定（`0x40DF0838` Far `L_Z` & `0x40DF08EC` Near `H_Z`）**：
   - 两函数均读取 **Property `0x157`**（`bl 0x41068b68`）：
   - 当 `prop_0x157 == 3` 时：分别调用 Hotline 端止读数函数 `0x40DF222C`（Far，`== 1` 为触达远端止）与 `0x40DF2270`（Near）；
   - 当 `prop_0x157 == 1` 时：`0x40DF0838` 取出镜头逻辑远限 `[x20 + 0x90]`（`L_Z`），乘以 `10`（`w8 + (w8 << 2)) << 1`）并与目标脉冲 `w19` 比较（`>= w19` 返回 `1`），或回退到 `0x40dd5cf0` 比较 `10 * [arg_4h] >= w19`；`0x40DF08EC` 对称地读取 `[x20 + 0x9c]`（`H_Z`）比较 `10 * H_Z <= w19`。
   - 注：由此可见 Z8 内部位置比较标度与镜头 `CMD 0x20` / `CMD 0x12` 原生位置字存在固定 `10×`（或端止缩放）对应关系，桥接端必须在协调 `L_Z / H_Z` 与 `CMD 0xC0` 目标值时保持同一原点与标度。
2. **盲搜/限位反转（`0x40DCFA8C` -> `0x40DD0B40` -> `0x40DD1FF4` -> `0x40DD1768`）**：
   - `0x40DCFA8C` 查询端止（`0x40dd5c8c`/`0x40dd5d24`）、通过 `0x40defc30`/`0x40df22c4` 决策扫描方向 `[x21+0x2d0]`、调用 `0x40dd36b8`/`0x40dd36a0` 计算扫描速度 `w26`（默认 `0x19`）、检查光瞳门 `0x40DCA360` 并组装参数块调用 `0x40DCDB2C`。
   - `0x40DD0B40` 在盲搜期间每周期监测：若 `[x21+0x90] == 1`、`((0x40defc60() | 1) == 9)` 或 `[x22+0x2bc] == 2`（`0x40dd0bb8`），**立即放弃并置 `*sm = 7`**（`0x40dd0bc0..0x40dd0bc8`）。正常搜索期间于 `0x40dd0c08` 起记录全局坐标 `0x0A037D1630`；一旦连续样本数 `[x9+0xd] >= 5`（不移动）且持续时间 `(cur_ts - [x9]) > 0x1E8480`（**`2,000,000 us = 2.0 s`**，`0x40dd0c58`），立即触发 **`0x40dd570c` 墙体停滞超时/放弃**。
   - `0x40DD1FF4` 根据 `[x20+0x2bc] == 2` 或模式条件 `0x40defe5c()` 分流：满足结束或反转条件时调用 **`0x40DD1768(ctx, mode)`**（mode `0` 或 `1`）执行端止检测（同时调用 `0x40DF08EC` 与 `0x40DF0838`）及 CDAF/过峰回退准备；未触及则锁存 `[x20+0x2d6] = 1` 并派发下一步 `0x40DCDB2C` 搜索指令。
3. **合焦确认/转绿状态机（`0x40DCBC00` -> `0x40DCBDA4` -> `0x40DCC854`）**：
   - `0x40DCBC00` 先以 `0x40dcb288` / `0x40dcb31c` 检查中止/异常条件（异常时写 `*sm = 0xFE` 并返回错误码 `1/2/3`），通过 `0x40dcba1c` 后读取 `[x20+0x6a94]` 判定是否执行恢复微跳——若 `[x21+0x90] == 1` 或 `0x40defc60() - 6 >= 2 && [x21+4] == 1` 则调用 **`0x40DCE078`**，由后者计算微步偏移 `w19 = [x22+0x884] + ([x22+0x6a8c] / 256)` 并下发 **`0x40DCE154`**；正常分支将状态切为 `*sm = 9` 并进入 **`0x40DCBDA4`**（状态 `0..7` 跳转表 `0x0A029E8060`）。
   - 在 `0x40DCC854` 中，固件分别根据阶段标志 `w9 == 1` 或 `w9 == 2` 检查 Hotline/镜头静止采样计数器 **`[x19+0x694d]`** 与 **`[x19+0x694e]`**；只要有效静止计数 **`> 4`（即连续 `>= 5` 帧静稳）**，随即跳转 `0x40DCC94C` 写入 **`*sm = 0x0A`** 并置位完成标记 `[x19+5] = 1`——这正是机身取景框由白/红转为**合焦绿框**并释放快门的直接门控判据。

### 1.5 CDAF 过峰回退、有符号 7-bit 速度编码与驱动命令打包

1. **有符号 7-bit 速度编码（`0x40DEE9D8` 与 `0x40DEF25C`）**：
   - `0x40DEF25C(dst, active, val)` 先将输出缓冲 `[x0+0]` 置 `0xFF`、`[x0+1]` 置 `0x3F`，仅当 `active == 1` 时尾调用 `0x40DEE9D8(speed, x0+1, x0)`，把连续速率编码为 Z 卡口 7-bit 速率字节写入 `mosi[5..6]`（若编码值 `val == 0` 或特殊停滞码则进入不限速直达路径，具体换算式见 Part 3 §1.3）。
2. **`CMD 0xC0` TX 构建器 `0x410A005C` 与 `mosi[11]` 位域**：
   - `0x410A005C`（`z8_spi_af_cmd24_txrx.txt`）将主机命令结构打包为 `18 B` `CMD 0xC0` 请求：
     - `mosi[1..4]`：`raw_1`（`int32_t` 相对位移脉冲，由 `0x40DED568` / `0x40DED5FC` 根据控制模式填入）；
     - `mosi[5..6]`：`0x40DEE9D8` 生成的速度/方向编码字节；
     - `mosi[11]`（`strb w9, [x1, 0xb]`）：精确位打包指令如下——`bit7 = [x0+0x0c]`、`bit5 = [x0+0x10]`、`bit3 = [x0+0x14]`、`bits[2:1] = ([x0+0x18] << 1)`、`bit0 = [x0+0x1c] & 1`。在 `0x40DCDB2C` 正常 AF 驱动分支下，`[x0+0x0c]/[x0+0x10]/[x0+0x18]` 保持为 `0`，因此 **`mosi[11]` 仅合法出现 `{0x00, 0x01, 0x08, 0x09}`**；
     - `mosi[12]`：自增滚动 `cookie`（来自 `0x0A045C5718`）；
     - `mosi[13..16]`：`raw_13`（`int32_t` 绝对目标或方向性端止护栏；当 `raw_1 != 0` 时作为同向到达钳位，当 `raw_1 == 0` 时作为绝对落点或壁哨兵）。
3. **刹车/急停掩码差异（`CMD 0xE2 / 0xE6` vs `CMD 0xC0 / 0xE4 / 0xE8`）**：
   - 对照 Z8 TX 生成路径（`0x410A043C` / `0x410A04C0` / `0x410A0578`）与 Part 1 §5 实测 Nikkor Z 镜头固件解码规则：`CMD 0xE2 / 0xE6` 的控制字节在偏移 `7` 处按 **`and #6; cmp #6`**（即仅 `(byte7 & 0x06) == 0x06` 才触发刹车），而 `CMD 0xC0`（`mosi[11]`）、`CMD 0xE4`（`mosi[9]`）、`CMD 0xE8` 按 **`tst #6`**（即 `(ctrl & 0x06) != 0` 即任意置位 `bit1` 或 `bit2` 均执行减速停稳）。

### 1.6 光瞳加权、热区监测与 Release/VR 时序接口

- **瞳面光瞳加权（`0x40DCA360` / `CMD 0x20[0x15..0x24]`）**：
  - `CMD 0x20 sub 0x00` 接收函数 `0x410A1E20`（`z8_spi_init_txrx.txt`）将镜头响应偏移 `0x14..0x24` 原封不动拷贝至 `Bank 0x0C` 的偏移 **`0x15..0x25`**（覆盖 `0x15..0x24` 光瞳/入出瞳光学段），并将 `0x63..0x100` 写入 `Bank 0x0D`。
  - 在 `0x40DCFA8C`、`0x40DCE1BC`、`0x40DCE7B4`、`0x40DD1AFC`、`0x40DD1B78` 及 `0x40DD2B90` 等 `K_Z` 与搜峰入口之前，固件统一先调用 **`0x40DCA360`** 判定光瞳条件；当其返回 `1` 时通过 `0x40DD3AD0` 写入 `[x19+0x2f4]` 并查光瞳加权矩阵再进入 `0x40DB76B0`，否则跳过光瞳补偿或将输出槽置无效标志 `0x7FFFFFFF`。
- **热区读数与快门释放 / VR 时序接口**：
  - 温度消费点 `0x41076274` 轮询 **Property `0x049`**（`Bank 0x0B + 0x71`），发现与缓存 `0x0A045A2144` 不一致时通过 `0x410711dc` 更新镜头温度状态并上浮至控制层事件表；
  - 释放与特性联合查询 `0x41083BB0` 读取 **Property `0x04B`** 及相邻 **`0x04C..`** 等 6 项（`bl 0x4109e198` 循环读取 `w0 = 0x4b, ...`）合成释门/VR 约束块；
  - 节拍步进监控 `0x4107B440` 查询 **Property `0x078`**（非全速模式 `0x1000` 时取 `prop_0x78 << 1`），按剩余总量钳位进度百分比（上限 `100` / `0x64`）后向回调表提交事件 **`0x04270106`**；
  - 同步释放事件派发链 `0x41067DB8` / `0x41067E20` / `0x41067E88` / `0x41067EF0` 通过 `0x4106B294` 经 `0x410862a4` 唤醒释门与防抖同步任务（事件编码 `0x3C00` / `0x3000` / `0x2400` / `0x1C00`）。

## 2. Sony 原厂 E 卡口协议与 `A1 II (V4.00)` / `A9 III` 机身架构

本节全部固件事实均核验自 Sony `A1 II V4.00` `cpapp-b.bin`（`19,190,024 B`，SHA256 `96b41427958c1b412b3e15c5bd9b51e34657ae1e1246344438b8368031ca4859`，ARM Thumb LE）与 `A9 III` `cpapp-b.bin`（`20,872,312 B`，SHA256 `5da0e9124aa927f2b2fc7b47fb362522cd617fd647a4ccd45e34a5784ac675fe`）（证据文件 `sony_3p_final_check.txt`）。

### 2.1 物理触点、帧结构（`5-byte` / Burst / `type` 分类）、校验与波特率时序

1. **卡口 10 触点与物理方向定义**：
   - 采用镜头尾部正视左→右编号 **`E-L1..10`**（机身前视镜像 `E-B = 11 - E-L`），对照 Sony `ILCE-6000` Level 3 `CN1700`（16P FPC）（`boot-behavior/e-interface/README.md`）：
     - `E-L1` (`LENS_GND`)、`E-L2` (`LENS_POWER` 马达电源 `4.8–7.4 V`)、`E-L3` (`LOGIC_GND`)、`E-L4` (`BODY_VD_LENS` 帧同步脉冲，A6000 实测约 `59.94 Hz` / `16.684 ms` 周期)、`E-L5` (`LOGIC_VCC` `3.15 V` / `3.1 V`)、`E-L6` (`LENS_CS_BODY` 镜头握手/回包窗口界定)、`E-L7` (`LENS_DATA_BODY` RXD)、`E-L8` (`BODY_DATA_LENS` TXD)、`E-L9` (`BODY_CS_LENS` 机身发包窗口与换速握手)、`E-L10` (`LENS_XDETECT` 镜头接地、机身弱上拉在位检测)。
2. **线上帧格式、16-bit 校验和与零转义铁律**：
   - **Gen-2 标准变长帧**（`A6000` 实测抓包 `a6000_sel55210_init_55.sr`、`A1 II` / `A9 III`、`ETZ21` 及 `BORYOZA` 通用）：

```text
+------+--------+--------+------+------+---------------+----------+------+
| 0xF0 | len16  |  type  | seq  | cmd  | payload[0..N] |  sum16   | 0x55 |
|  1B  |  2B LE |   1B   |  1B  |  1B  |     N B       |  2B LE   |  1B  |
+------+--------+--------+------+------+---------------+----------+------+
```

   - 其中 `len16 = N + 9`（全帧总字节数），校验和按纯字节模 $2^{16}$ 累加：`sum16 = sum(wire[1 .. len16 - 4]) & 0xFFFF`；**线上载荷与头尾内出现的 `0xF0` / `0x55` 全字节原样透传，不存在任何 `0xF0` 双字节转义**（见 [lens_session.c](../../se-nz/src/02_core/lens_session.c) 与 [BORYOZA_NEW_FW_DESIGN_SPEC.md](HC32F460_SE_NZ_DESIGN_SPEC.md)）。
   - **`frame_type` 与报文粒度分类**：
     - 线上外层 `wire[3]` 主枚举为 **`type = 0x01`（`SYNC` 周期同步突发帧：携带 `ID03/ID04/ID05/ID06` 组合记录，AF 控制块嵌套 `5 B` `0x1D`、停稳 `1 B` `0x1C`、`8 B` `0x3C` 或 `14 B` `0x1F` / `0x43` 子记录）** 与 **`type = 0x02`（`B2L` 初始化/状态查询单命令帧：`CMD 01/07/08/09/0A/0B/0C/0D/10/3A/3B/3D/3F/4B/4C/5A/5F` 等）**。
     - 历史逆向与早期 Gen-1 文档中常见的两种区别：其一为早期 NEX/Gen-1 短帧省略 `len16/type/seq`，直接采用 `[0xF0 | cmd | ... | sum16_le | 0x55]`（`entropy-readme.txt`）；其二为 Samyang 原生 Bootloader/B2L 诊断扩展使用 `[0xF0 | len16 | SUBCMD | payload | sum16 | 0x55 0xAA]`（见 §3）。
3. **波特率协商与 `60 Hz` vs `120 Hz` 协议门控**：
   - 物理初始化一律从 **750,000 bps (8N1 LSB)** 起始（`HC32F460 USART1 OVER8=1 BRR=0x0FFF`，`SAMD21 BAUD=0xC000`）。当镜头在 **`CMD 0x0C`** 应答 `reply[1].bit0 == 1` 后，双方拉高 `BODY_CS_LENS` (`PA2`) 与 `LENS_CS_BODY` (`PH2`) 进入无数据高电平窗口（`A6000` 实测 `5,113 us`；`BORYOZA` 保持 `PA1 LTE=1` 锁高 `2 ms + 3 ms`），停发改分频切换至 **1,500,000 bps (`BRR=0x07FF`)**。
   - **机身 `120 Hz` (`0x78`) 门控（实测 `A1 II` `0x00436A00`）**：`A1 II` 在 `sony_a1ii_proto_cmds2.txt` 与 `final_gap_closure.txt` 的 `0x00436a6a` / `0x00436a88` 处读取全局帧率变量 `[0x018DA888]` 并执行 `cmp r1, 0x78`（`120`）；若当前帧率低于 `120 Hz`（`lo`），即执行 `movlo r0, 0x10` 回退至标准步距/单倍速率模式。且 Sony 与 Sigma 的实际 `120 Hz` 运行要求满足高速串口 `1.5 Mbps`（部分高刷扩展要求 `CMD 0x5F` 与/或 `TX08` 能力位确立）。
4. **Gen-1 / Gen-2 `CMD 32 / 5A / 0A` 初始化与 `0x807B`（`FE 50–150mm F2 GM`）实测约束**：
   - 基于 `A1 II`、`ETZ21` 原固件与 `sony50150-af-source.md` 的机器执行交叉对照：
     - 面向高阶 GM 镜头（如 `SEL50150GM`, `LensID = 32891 = 0x807B`），`ETZ21`（`0800B8E4..0800B930`）在读到 `TX07 family=2` 且状态位 `== 4` 时发送 **`CMD 0x32` (`32 80 01 00 00 00 00 00`)** 后发送 **`CMD 0x5A`（56 B：命令 + 32 B 能力降级掩码 `FF 9F 7F 5F 80 07 0E 00 00 00 00 02 ...` + `0x1F` + 22 B 零）**，`A1 II` 在 `0x00B31790` 使用完全相同输入可产出**逐字节一致的 56 B `CMD 0x5A` 帧**；
     - 在此 `5A` 降级掩码下，`cap(1D)=1, cap(5A)=1`，而 `cap(3C)=0, cap(43)=0, cap(49)=0`；原厂 `A1 II` `0x00AF6892` 无论输入 `class=1/4/5` 均走普通 `0x1D` 路径（`1D ... 3C` 相对步进 + `1D target 00 00` 绝对落点），故 `32/5A` 并不禁用 `0x1D`；
     - **`CMD 0x0A` `record[10].bit0` 差异判据**：`A1 II` `0x00B2DB8C..0x00B2DBA2` 仅在 **`session_class == 5 && cap(5A) == 1`** 时置 `record[10].bit0 = 1`（`class=4` 时保持 `00`），而 `BORYOZA` 当前生产 [lens_session.c](../../se-nz/src/02_core/lens_session.c) 按 `has_ext_5a` 置位；两者的条件范围边界必须在抓取实际 `TX07/32/5A/0A` 应答时对齐。

### 2.3 `ID04` AF 执行与降级通道、`ID06` 与 `ID05` 18 组遥测

1. **`AF6892`（`0x00AF6892`）扩展 vs 降级判据**：
   - 先调用能力查询 `0x00B2C8BE(0x43)`（查镜头 `cap32` 第 `0x43` 位），再调用全局扩展开关 **`0x00B2CBD8()`**；
   - 仅当两门均返回 `1` 时，跳转 `0x00432B04`（`"BL:MOVE_FC_A"`）组装扩展命令 `0x43`；任一门未通过（如降级 `5A` 掩码清除 `0x43` 位），无条件走 `0x00AF68F2..0x00AF6902` -> **`0x00432A80`**（`"BL:MOVE_FC"`）发送标准 `5 B` **`0x1D`** 命令。
2. **`ID04` 子记录格式（`0x00436A00..0x00436B46` & `af_servo_bridge.c`）**：
   - **`0x1C`**（`1 B`）：急停/制动子记录（`[0]=0x1C`），将执行器在当前物理位刹停。
   - **`0x1D` 绝对落点**（`5 B`）：`1D | tgt_lo | tgt_hi | 00 | 00`，直接指令驱动至 E 编码器目标位置 `target_se`。
   - **`0x1D` 相对步进**（`5 B`）：`1D | step_lo | step_hi | sgn_ext | flags`——`family=2` 扩展模式 `step < 0` 时 `byte3 = 0xFF, byte4 = 0x3C`（正步 `byte3 = 0x00, byte4 = 0x3C`）；标准/传统模式 `byte3 = 0x00, byte4 = 0x2C`。
   - **`0x3C` 恒速扫描**（`8 B`，`0x00436B20 -> 0x00AF4842`）：`3C | ctrl | vel_lo | vel_hi | 00 00 00 00`，其中 `ctrl = 0x01 | (seq_3c << 2)`，`vel` 为按 `defocus_k_se` 缩放后的有符号 16-bit 速度（`V2.16` 针对 Sony/Tamron 要求低 4 位对齐 `0xFFF0` 规避静摩擦，Sigma/C149 采用 ceil 最小步进下限）。
   - **`0x1F`**（`14 B`，`0x00436AFA`）：带附加速度/斜率廓线的扩展移动记录。
   - 另 `ID04` 主头字节 `byte[9]` 为伺服电源控制（`ID04_B9_SERVO_ON` vs `ID04_B9_IDLE_MF`），`byte[16]` 承担 APS-C/停机标志控制（`ID04_B16_APSC_STOP`）。
3. **`ID06` 反馈与 `0x00AA2A32`（`A1 II`）/ `0x00AA4084`（`A9 III`）`defocus_k_se`**：
   - `ID06` 返回实时位置 `S_E`、`hw_moving`（硬件马达运动标志）、端止命中状态、`limit_inf / limit_near` 及实时镜头对焦灵敏度 **`defocus_k_se`**。
   - 在机身离焦转换层，`A1 II` 的 `0x00AA2A32`（由 `0x00A918E0` 传入当前帧参数调用）与 `A9 III` 的 `0x00AA4084` 从 `0x00AF070C` / `0x00AE9E9A` 获取灵敏度并执行 `(K * factor + 0x800) >> 12` 及 `sdiv` 缩放换算脉冲目标步长。
4. **`ID05` 18 组动态遥测（`0x004579E4` / `0x00458800` 解析，`GRP05_LEN[18]`）**：

## 4. Z8 <-> E-mount 闭环耦合约束与桥接映射速查表

在桥接固件（[af_servo_bridge.c](../../se-nz/src/02_core/af_servo_bridge.c)、[vr_duty_controller.c](../../se-nz/src/02_core/vr_duty_controller.c)、[lens_session.c](../../se-nz/src/02_core/lens_session.c)）中，Nikon Z8 控制环与 Sony E 镜头执行器必须在坐标、端止、速率与收敛判据四层严格耦合；对应的历史缺陷与已知陷阱索引至 [part3_ez_bridge_known_bad_errata.md](PART3_EZ_BRIDGE_AND_ERRATA.md)。

### 4.1 坐标、端止对齐与闭环收敛方程

1. **坐标仿射对齐（$C_Z \leftrightarrow S_E$）与绝对零点锚定**：
   - 将 E 口原始位置（无符号 16-bit，禁止有符号截断，覆盖 Tamron `32768..40000`）按定标远限锚点 `e_inf_cal` 线性缩放至 Z8 有符号 32-bit 逻辑脉冲空间（`0 = 无穷远基准`，正值向近距递增，对应 `af_servo_se_to_cz` / `af_servo_cz_to_se`）：

$$C_Z = \text{round}\left( (S_E - S_{E,\infty,\text{cal}}) \cdot \frac{\text{span}_Z}{\text{span}_E} \right)$$

$$S_E = S_{E,\infty,\text{cal}} + \text{round}\left( C_Z \cdot \frac{\text{span}_E}{\text{span}_Z} \right)$$

   - 变焦、三档限位拨杆或重启均不得改写锚点 `e_inf_cal`（消除坐标系漂移，对照 `KB-11` / Errata `(g)`）；动态限位由 `ID06` 实时 `limit_inf / limit_near` 直接投影为 `CMD 0x20` 软边界 `[L_Z, H_Z]`，保证 Z8 `0x40DF0838` (`Far L_Z`) 与 `0x40DF08EC` (`Near H_Z`) 的边界判定与 E 端止完全重合。
2. **速度编解码与 `K_Z` 闭环倍率耦合**：
   - Z8 通过 `CMD 0xC0 / 0xE2 / 0xE4 / 0xE6 / 0xE8` 下发有符号 7-bit 速度编码（`0x40DEE9D8`），桥接端解码得到目标速率 $v_{Z,\text{pps}}$，同时以 `0x40DB76B0` 线性敏感度约束计算对应 E 口单帧名义步进 `compute_vsync_step_se`；对启用了 `sigma_150600_thermal_vmax_tps` 的镜头，E 侧目标步进须叠加温度区限速。
   - **刹车掩码严格区分**（`af_servo_bridge.c:L1406,1573`）：解析 Z8 请求时，`CMD 0xE2 / 0xE6` 仅在 `(mosi[7] & 0x06) == 0x06` 时触发 `issue_controlled_brake`；`CMD 0xC0`（`mosi[11]`）与 `CMD 0xE4`（`mosi[9]`）在 `(ctrl & 0x06) != 0` 时立即制动。
3. **`STEP_ACT_ABS` 死区收敛与防卡死门控**：
   - 单次与连续 `0x1D` 步进由 `decide_singleshot_1d` / `decide_continuous_1d`（`af_servo_bridge.c:L972-1071`）与 `eval_fam2_approach` 仲裁：当剩余误差 $|S_E^{\text{tgt}} - S_E| \le \text{step\_vd}$、`abs_err <= capture_tolerance_se(ctx)`（系数 `span / 3072`，钳位 `2..6`）、或 `fam2_ext` 预测下一帧将跨零到达时，立即切换动作枚举 **`STEP_ACT_ABS`**，输出 `1D | target_se_le | 00 00` 强制精确落点并清零累积脉宽，消除小死区内 `0x3C` 静摩擦振荡与超调。
   - 当 `abs_err <= deadband_tolerance_se(ctx)`（系数 `span / 1024`，钳位 `4..14`）且 **`ID06.hw_moving == 0`**（或连续稳定帧满足条件）时，向 Z8 `SPI1` 热线 `HOT[6]` bits `[5:4]` 上报停稳/到位状态（驱动 `0x41078348` 投递 `event 0x3C` `result_code = 2`），使 Z8 合焦状态机 `0x40DCC854` 在累计 `>= 5` 帧静稳后推进 `*sm = 0x0A` 合焦转绿；若位置卡滞超过 `active_stall_guard_vsyncs`，桥接端主动发送 `0x1C` 中止 (`emit_stall_abort_stop`) 并置错位通知 Z8，防止触发 Z8 `0x40DD0B40` 的 `2.0 s` (`0x1E8480 us`) 搜索冻结或永久放弃。

   - 会话持续维护 Z 逻辑坐标锚点 `ext->parfocal_cz_anchor`。在激活 AF 追焦态变焦时，实时将 `servo->target_se` 与 `servo->cmd_vel_se_pps` 重投影至新焦段凸轮端点；在空闲或机身侧 MF 态（`is_mf_switch == 0 && mf_hold_frames_rem == 0`）检测到焦距或变焦码跨越（`|dzoom| >= 16`）时，置位 `ID04[9] = 0x81` 等待齐焦建立，待变焦与马达停稳 `2` 个 VSync 后若偏差超出 `closed_loop_moved_tol_se` 则下发单次 `1D <trim_se> 00 00` 微修。
   - 用户物理拧动镜身对焦环或切换镜身 MF 开关期间，实时刷新 `parfocal_cz_anchor = cur_cz` 并保持纯粹手动随动响应。
3. **Sony `1.4x / 2.0x` 增距镜（`0x8130..0x8148`）与变焦双端 MFD 线性插值**：
   - 目录（`gen_lens_db.py`）对带 `SEL14TC / SEL20TC` 的原生复合 `LensID`（`0x8130..0x8148`）直接登记增距后等效焦距与最大光圈，并在 `CMD 0x10[0x19..0x1A]` 保持 `00 00`，交由镜端统一完成倍率乘算。
   - `af_servo_effective_mfd_meters` 按当前焦距在 `(mfd_mm, mfd_tele_mm)` 区间执行线性插值（如 `0x807B` 从广角 `0.40 m` 连续过渡至长焦 `0.74 m`，同时保持 `mech_hz = 40,960` 的柔顺 CDAF 雅可比）。
4. **Tamron `C145/F072` 与 Sigma `C55A/C551` 微距 `(c0, c1)` 光学拆解（研究归档，固件保持 `c1 = 0`）**：
   - 在 `Z8 3.12` `0x40DB76B0` 有理分式模型中，$c_0$ 描述一阶轴向灵敏度随离焦变化率，高放大率（$\beta \to 1.0$）下受有效光圈 $F_{\mathrm{eff}} = F(1 + \beta)$ 与瞳比 $p = z_{\mathrm{exit}}/z_{\mathrm{entrance}}$ 强烈调制。
   - 原生固件实证：`Tamron F072 90mm F/2.8 Macro VXD`（`0xC145`）运行 `Slave_Tick @0x08056886` 驱动 `145` 节点双 VXD 浮动凸轮（`@0x0807D150`），从无穷远到 `1:1` 末端 `dG2/dG1` 由 `0.3023×` 跃升至 `1.2626×`、散焦灵敏度由 `1,397` 升至 `3,610`（`2.584×`）；`Sigma C55A 105mm F2.8 DG DN Macro`（`RX65N @0xFFF50BE0`）`22` 段螺距 `605 -> 517`（变化 `1.170×`，`0.5F` 系数）；`Sigma C551 70mm F2.8 Art Macro`（`RX63T`）机械外伸双组凸轮固定 `4096..28296`、灵敏度跃升 `3.734×`。研究结论归档于本文档及 Part 4，V2.19 固件在 `CMD 0x20[0x65..0x66, 0x6B..0x6C]` 保持 `0x0100`（`c1 = 0`），由实时 `ID06.defocus_k_se`、`aperture_indep_f2_base_k` 与无极点 `c0` 闭环统一覆盖。
