- **文档版本**：v2.0（经全覆盖红队排错审计、Z8 AArch64 原码仿真与 ExifTool 闭环验证定稿）

## 1. 设计目标与全生态兼容矩阵

### 1.1 核心工程指标
1. **算力与确定性实时架构**：启用超高速电源模式与 `192.000 MHz` Cortex-M4F 主频、硬件单精度 FPU（`fpv4-sp-d16`，`-mfloat-abi=hard`）、`EFM` 缓存与预取（`EFM_FRMC = 0x00010050`）、`32 KiB SRAMH` 零等待单周期热路径、5 路 AHB DMA 与 `TMRA1` `3.000 MHz`（`0.333 µs`）64-bit 单调硬件时基；仅保留 4 个驻留 `SRAMH` 的极短整数硬件中断，主循环单圈调度延迟 `< 1 µs`。
2. **机内对焦限位器（`0.1–999 m`）与全查看器 EXIF 对焦距离原生闭环**：
   - 在 `cmd10 TX[0x0B]` 按镜头最大焦距自适应申报标度指数 `n << 4`（`f_max < 200mm` 取 `n = 7 -> 0x70, A = 16384.0`；`200..399mm` 取 `n = 9 -> 0x90, A = 65536.0`；`f_max >= 400mm` 如 `Sigma 150-600` 取 **`n = 10 -> 0xA0, A = 131072.0`** 以保障 `600mm` 远摄端零量化损失），将热线 `s32 C_Z` 脉冲域连续光滑标定至双曲倒数米制域 $C_{\text{Z}} = \text{round}(A / D_{\text{m}})$ 并按局部雅可比斜率联动缩放散焦灵敏度与伺服速度，彻底根除 `995m / 999m` `INT_MAX` 死窗故障；
   - 同步维护 `cmd10 TX[3..6] = 00 01 00 01`（`LensData+0x35 = 1`）、`cmd20/00 Z_wire[0xBB..0xBC]`（`LensData+0x58` 无穷远置 `0`、有限距离置 `1..36`）与 `Z_wire[0x2F..0x30]`（有限距离钳位 `[0x0008, 0xFFF7]`、无穷远置 `0xFFFF`），确保尼康 NX Studio、ExifTool `12.x` 与 `13.x` 及全系第三方看图软件准确显示物距与 `Inf`。
3. **机身全画幅 / 残幅通用自适应**：面向 **24MP 全幅**（Zf / Z6 III，`5.94 µm`）、**45.7MP 全幅**（Z8 3.10/3.12 / Z9 / Z7 II，`4.35 µm`）与 **21MP–40MP APS-C 残幅**（Z50 II / Zfc，`3.04–3.75 µm`）统一上报物理光学量纲（`pulses/mm`、`16×f_mm`、`Q2.14` 倍率、`DX/FX` 像场标志）。
4. **真值光谱白平衡补偿（`cmd24` `[6977:7156)` `179B` 严格限实测 `T(λ)` 曲线）**：对腾龙同款镜头装入原厂 Z `cmd24` 81 点（`380..780 nm, 5 nm`）光谱曲线；对适马无反全系装入由 L 口 `.plf` `EXT_06` 实测 `T(λ)` 三次样条重采样的 81 点曲线；对仅含双标量 `(Rratio, Bratio)` 的镜头统一填全 `0x00`（Z8 返回 `[32768, 32768]` 单位白平衡增益）。

## 2. Bootloader 交接契约、Flash 分区与五段 SRAM 精确规划

### 2.1 原厂 Bootloader 交接 ABI 与打包门禁
1. **相机挂载冷启动入口**（`PA9` 在复位释放后由机身侧采样为低电平）：
   - BL 完成 `0x4200` UID 配对校验后在 `0x1134` 执行 `CPSID I`（`PRIMASK = 1`），加载 `MSP = *(uint32_t *)0x00010000`，跳转 `BLX (*(uint32_t *)0x00010004)`（bit0 恒为 `1`）。
   - 入场硬件态：特权 Thread 模式，`VTOR = 0`，`FPU CPACR = 0x00F00000`，系统时钟 `MRC 8 MHz`（`XTAL` 与 `MPLL` 停止），`SRAMC_WTCR = 0x00001100`（仅 `SRAM3` 1-wait，`SRAM1/2/Ret` 为 0-wait），`PWC_RAMOPM = 0x8043`。
2. **USB 升级容器契约（`pack_pub.py` 强制门禁）**：
   - 容器格式：`PUB = "PRODUCTVER:1.001" (16B) + raw_APP (补 0xFF 至 512B 整扇区对齐)`；
   - 分区隔离断言：`Q = (16 + len(raw_APP)) // 512`，强制断言 `program_end = 0x10000 + Q*512 - 16 <= 0x00060000`；
   - 扇区头防碰撞断言：对所有 `k >= 1` 强制校验 `PUB[k*512 : k*512 + 16] != b"PRODUCTVER:1.001"`，阻断分块写入二次全擦；
   - `README.TXT` 版本显示槽：`VA 0x00011000` 固定放置 `{0x00, 0x02, 0x0B, 0x1A}`（显示 `V2.00 2026-11`，与 Z 线上 `cmd10 TX[3..6]` 完全解耦）。

### 3.2 `192.000 MHz` 时钟树、超高速供电与外设寄存器精确值（100% 经 SVD/DDL 与 V120 校验）
1. **五步升频与等待/电压切换硬性顺序（`sys_clock_sram.c`）**：
   - **Step 1（SRAM 等待周期）**：写 `SRAMC_WTPR (0x40050804) = 0x77` $\to$ 写 `SRAMC_WTCR (0x40050800) = 0x11001111`（`SRAMH = 0-wait`，`SRAM1/2/3/Ret = 1-wait`）并读回确认 $\to$ 写 `SRAMC_WTPR = 0x76`；确认 `PWC_RAMOPM (0x40054018) == 0x8043`。
   - **Step 2（EFM Flash 等待与缓存）**：当 `(EFM_FAPRT & 1) == 0` 时依次向 `EFM_FAPRT (0x40010400)` 写 `0x0123`、`0x3210` $\to$ 写 **`EFM_FRMC (0x40010408) = 0x00010050`**（`FLWT = 5 [7:4]`，`CACHE = 1 [16]` 同时启用缓存与预取，`LVM = 0`，`SLPMD = 0`）并读回确认 $\to$ 写 `EFM_FAPRT = 0x0000` 锁存。
   - **Step 3（超高速电源模式 `UHS`）**：写 `PWC_FPRC (0x400543FE) = 0xA502` $\to$ 写 `PWC_PWRC2 (0x40054402) = 0xCF`（8-bit）、`PWC_MDSWCR (0x4005440F) = 0x10`（8-bit）$\to$ 循环延时 `>= 30 µs`（MRC 8MHz 下 `>= 240 cycles`）。
   - **Step 4（总线分频与 16MHz 外晶起振）**：写 `PWC_FPRC = 0xA501` $\to$ 写 `CMU_SCFGR (0x40054020) = 0x00112210`（`HCLK = PCLK0 = 192 MHz`，`PCLK1 = PCLK4 = EXCLK = 96 MHz`，`PCLK2 = PCLK3 = 48 MHz`）$\to$ 写 `CMU_XTALCFGR (0x40054410) = 0x80` $\to$ 写 `CMU_XTALCR (0x40054032) = 0x00` $\to$ 轮询 `CMU_OSCSTBSR (0x4005403C) & 0x08` (`XTALSTBF == 1`)。
   - **Step 5（MPLL 锁定与主时钟切换）**：写 **`CMU_PLLCFGR (0x40054100) = 0x11102F01`**（`PLLSRC = 0` 选 16MHz XTAL，`MPLLM = 1` 即 `/2 -> 8 MHz PFD`，`MPLLN = 47 (0x2F)` 即 `*48 -> 384 MHz VCO`，`MPLLP = 1` 即 `/2 -> 192.000 MHz`，`MPLLQ = 1`，`MPLLR = 1`）$\to$ 写 `CMU_PLLCR (0x4005402A) = 0x00` $\to$ 轮询 `CMU_OSCSTBSR & 0x20` (`MPLLSTBF == 1`) $\to$ 写 `CMU_CKSWR (0x40054026) = 0x05` $\to$ 写 `PWC_FPRC = 0xA500` 上锁。
   - **外设门控使能**：写 `PWC_FCG0PC (0x40048010) = 0xA5A50001` 解锁 $\to$ 清零 `FCG0` 的 `bit14 (DMA1)`、`bit15 (DMA2)`、`bit17 (AOS)`，清零 `FCG1` 的 `bit16 (SPI1)`、`bit18 (SPI3)`、`bit24 (USART1)`，清零 `FCG2` 的 `bit2 (TMRA1)`、`bit5 (TMRA4)` $\to$ 写 `PWC_FCG0PC = 0xA5A50000` 保护。

2. **三大通信外设硬件位宽、端序与触发规则**：
   - **`SPI3`（`0x40020000`，Z 主通道从机）**：
     - `CFG1 = 0x00000010`、`CFG2 = 0x00001C07`（`CPOL=1, CPHA=1` Mode 3，`DSIZE=0xC` **16-bit**，`LSBF=1` LSB-first）、`CR1 = 0x00000001`（停态）/ `0x00000041`（运行态，三线从机全双工）。
     - **零字节翻转小端直通定理**：`DMA1 CH0 (RX)` 与 `DMA1 CH1 (TX)` 均设 `HSIZE = 1`（16-bit 半字），缓冲区强制 `aligned(4)`。小端内存中 `*(uint16_t *)&buf[2*k]` 低字节为 `buf[2*k]`（`bits[7:0]`）、高字节为 `buf[2*k+1]`（`bits[15:8]`），`SPI3` 在 `LSBF=1` 下先移出 `bits[0..7]`（即 `buf[0]=0x55` 的 bit0 最先上线），紧接着移出 `bits[8..15]`（`buf[1]`），**内存字节数组天然与 Z 物理线序 100% 等价，严禁做任何半字字节交换**！`DTCTL.CNT` 严格装填半字数 `N / 2 = len16 + 1`。
   - **`SPI1`（`0x4001C000`，Z 1kHz 42B 状态热线主机）**：
     - `CFG1 = 0x00000010`（`MIDI = 0`）、`CFG2 = 0x0000F413`（Mode 3，`MBR = 4` $\implies 96\text{ MHz}/2^{4+1} = 3.000\text{ MHz}$，`DSIZE = 4` **8-bit**，`LSBF = 1`，`MIDIE = 1` 自动插入 1 SCK 字间间隔）、`CR1 = 0x0000000B`（停态）/ `0x0000004B`（仅发送主机）。
     - 每 `1.000 ms` 由 `DMA2 CH0`（`DTCTL = 0x002A0001` 即 42 个 8-bit）连续突发发出；收到 `IRQ40` (`DMA2_TC0`) 后在主循环轮询 `(SPI1->SR & 0x02) == 0`（`IDLNF == 0`，确认末字节移位完毕）再写 `SPI1->CR1 = 0x0B` 关闭 `SPE`。
   - **`USART1`（`0x4001D000`，E 口异步串口）**：
     - `PR = 0x00000000`、`CR2 = 0x00000000`、`CR3 = 0x00000000`、**`CR1 = 0x8000800C`**（`SBS=1` 下降沿起始检测，`FBME=0`，`ML=0` LSB-first，`OVER8=1` 8 倍过采样，`M=0` 8-bit，`PCE=0`，`TE=1`，`RE=1`）；
     - 波特率寄存器：`750,000 bps` 写 **`BRR = 0x00000FFF`**（`DIV_Integer = 15`），`1,500,000 bps` 写 **`BRR = 0x000007FF`**（`DIV_Integer = 7`）；

### 4.1 冷启动引脚与时序门控

### 4.2 E 口物理帧格式、零转义铁律与 `ID05` 18 组动态解包规范
1. **线上信封与零 `0xF0` 转义铁律**：
   - 所有 E 口帧统一为 `0xF0 | u16_le wire_len | u8 type | u8 seq | u8 cmd | payload[wire_len-9] | u16_le sum16 | 0x55`，其中 `sum16 = sum(wire[1 : wire_len - 3]) & 0xFFFF`；
   - **线上字节流 100% 原始透传（零 `0xF0` 双字节填充转义）**：载荷、长度或校验和中出现 `0xF0` 均按单字节原样收发；
   - **五重接收校验门禁（`e_usart1_dma.c`）**：`PH2` 下降沿结算 `rx_len = 2048 - (DMA2->MONDTCTL2 >> 16)` 后：① 若 `buf[0] != 0xF0` 则前向扫描首个 `0xF0` 剥离空闲线毛刺；② 校验 `8 <= wire_len <= rem_bytes`；③ 校验 `buf[wire_len - 1] == 0x55`；④ 校验 `sum16` 精确相等；⑤ 对 `ID05 / ID06` 校验 `wire_len - 9 >= expected_active_group_bytes`，不满足整包丢弃，保持上一完整 `epoch` 快照不被污染。
2. **`ID05` 18 组动态游标解包表**：
   以 `active_mask05 = req_mask05 & u32_le(tx0a_reply[1..4])` 从 `pos = 6`（即 `wire[6]`）起按位依次提取各激活组至固定结构体 `g_id05.grp[0..17]`，各组字节长度固定为：
   `GRP05_LEN[18] = {8, 1, 8, 3, 10, 28, 2, 6, 1, 2, 8, 6, 6, 6, 1, 6, 3, 3}`（前 15 组满掩码 `0x7FFF` 共 `96 B`，全 18 组满掩码 `0x3FFFF` 共 `108 B`）：
   - `grp[0]` (`8B`)：`+0..1 = u16_le dist_x`（`0xFFFF` 为无穷远，有限值 `x = 384 + 64*log2(D_m)`），`+4..5 = u16_le f_opt_0p1mm`，`+6..7 = u16_le f_nom_0p1mm`；
   - `grp[2]` (`8B`)：`+0..1 = u16_le P_cur`，`+2..3 = u16_le P_open`，`+4..5 = u16_le P_min`；
   - `grp[3]` (`3B`)：`+0 = u8 mag_code`（`!= 0xFF` 时 $\beta = 2^{5 - \text{code}/16.0}$）；
   - `grp[4]` (`10B`)：手动光圈环块，`+0..1 = u16_le P_ring`，`+2.bit0 = manual_ring_active`；
   - `grp[5]` (`28B`)：`+0..1 = s16_le Delta_AV`，`+2..7` = 暗角 6B 核心段，`+8..13` = 畸变 6B 核心段；
   - `grp[7]` (`6B`)：开关按键块，`+0..1` = 对焦环方向/步长，**`+2.bit1` = `AF/MF`（`0`=AF, `1`=MF）**，**`+4.bit3` = `AFL / Focus Set`（映 `L-Fn`）**，**`+4.bit4` = 实体防抖开关（`1`=ON, `0`=OFF）**，`+4.bits[6:5]` = 防抖模式 `1/2/3`；
   - `grp[11..13]` (`3×6B`)：倍率色差选择器与 R/B 双通道 6B 核心段；`grp[15..17]` (`6B+3B+3B`)：暗角/畸变/色差全画幅外圈 3 节点扩展尾段。

### 4.4 `PA3` 不断电热插拔状态机
主循环每 `5 ms` 采样一次 `PA3`：
- **拔镜检测**：在已连接态连续 10 次（`50 ms`）读到 `PA3 == 1` $\to$ 原子递增 `g_session_epoch++`，立即置 **`PA9 = 1`（Busy 高）** 关停 `SPI3` 与 `SPI1` 热线，停 `USART1` 并置 `PA1 = 0, PA2 = 0`，将 `TMRA4` 恢复默认 `60.000 Hz` (`PER=49999`)，清空旧镜头动态缓冲；
- **插镜重连**：在断开态连续 10 次（`50 ms`）读到 `PA3 == 0` $\to$ 重跑 §4.1–4.3 完整建链握手，填妥新镜头双缓冲快照后保持 `PA9 == 1` 满 `500 µs` 再拉低 `PA9 = 0` 重新向 Z 机身上线。

## 5. Z 卡口传输层与全帧逐字节精确定义（`SPI3` + `SPI1`）

### 5.1 `SPI3` 两阶段双窗协议与全命令分派表（`z_spi3_slave.c`）
- **阶段一（固定 8B 命令窗，`DMA1 CNT = 4` 半字）**：`55 | b1 | b2 | cmd | sub | len_lo | len_hi | hdr_csum`，校验 `rx[0] == 0x55 && (sum8(rx[0..7]) & 0xFF) == 0`。阶段二全双工窗口字节数**唯一由机身请求头决定**：$N = 2 \cdot (\text{u16\_le}(\text{len\_lo, len\_hi}) + 1)$（半字计数 `CNT = len16 + 1`）。
- **阶段二（$N$ 字节数据窗）**：拉高 `PA9 = 1` $\ge 10.0\,\mu\text{s}$ 期间装载响应缓冲（`tx[0] = 0x55`, `tx[N-1] = (-sum8(tx[0..N-2])) & 0xFF`；当 `N > 512` 时 `DMA1 CH0` 切 `CHCTL = 0x0100` 固定写哑元槽，`DMA1 CH1` 读 `SRAM2` 光学表），使能 `DMA1 CH0/CH1` 与 `SPI3` 后拉低 `PA9 = 0`。
- **全部 Z 卡口命令均遵守标准两阶段双窗协议**（含 `4B` / `6B` / `8B` 短数据窗命令）：

### 5.4 `SPI1` 1kHz `42B` 状态热线组装规则（`z_spi1_hotline.c`）
每 `3,000 ticks`（`1.000 ms`）构造双缓冲 `HOT[0..41]` 由 `DMA2 CH0` 发出：
- `HOT[0] = 0x55`，`HOT[1] = ++hot_seq`；
- `HOT[2..5] = s32_le(C_Z_interp)`：在光学净位移域 $\Delta S(t) = S_{\text{E}}(t) - E_{\infty,\text{true}}(z(t))$ 上按最近两包斜率线性外推（上限 `12 ms`）并映射至双曲米制脉冲域 `C_Z`；
- **`HOT[6]`（三段收敛状态机 + 硬件停稳判据）**：
  - 到位主判据：**`E 口 ID06 硬件运动位 == 0`**（或连续 2 帧位置恒定且已发包 `>= 1` VD 周期），彻底根除仅靠 `|S_E - T_E| <= 1` 导致的快门死锁；
  - `+C_Z` 正向运动期输出 **`0x1D`** $\to$ 到位过渡 2 帧输出 **`0x07`** $\to$ 静止输出 **`0x00`**；
  - `-C_Z` 负向运动期输出 **`0x1B`** $\to$ 到位过渡 2 帧输出 **`0x01`** $\to$ 静止输出 **`0x00`**；
  - 空闲态检测到手动拧动对焦环（`g_id05.grp[7][0..1] != 0`）时输出 **`0x08`**（`bit3=1, bits[5:4]=00b`）保持 5 帧触发全时手动干预；
- **`HOT[7]`（端点限位极性）**：**触达近端微距止点 (`H_Z`) 置 `0x01` (`bit0=1`)，触达远端无穷远止点 (`L_Z`) 置 `0x02` (`bit1=1`)**，行程内为 `0x00`；
- `HOT[8] = g_latest_af_cookie`（收到 `C0/C1/E0..EC` 后 `< 1 ms` 回显）；
- `HOT[9..12] = 0`；`HOT[13..20]` = 双轴 `s32_le` OIS 位移（未开 `0x5C` 填 `0`）；`HOT[21..40] = 0`；`HOT[41] = (-sum8(HOT[0..40])) & 0xFF`。

## 6. 核心业务域一：支持 `0.1–999m` 机内限位器的通用物理对焦伺服桥（`af_servo_bridge.c`）

### 6.1 双曲倒数米制 `C_Z` 坐标域、变焦齐焦零点跟踪与雅可比链式对齐
1. **未限位全行程齐焦无穷远基准 `E_inf_true(z)`**：
   - 内置凸轮库镜头（适马 19 款、腾龙 23 款、索尼 GM/G）直接按实时变焦编码 `z` 插值全行程光学无穷远轨迹 `E_inf_true(z)` 与最近对焦端 `E_near_true(z)`；未知镜头在未开限位握手阶段锁存 `ID06` 物理端点，并在镜筒限位拨杆或腾龙 LU 电子限位激活期间**锁定全行程 `E_inf_true(z)` 不随 `ID06` 限位窗口跳变**，同时在变焦过程中精确跟随光学齐焦偏移（例如 `Sigma 150-600` 从 150mm `9093` 平滑跟踪至 600mm `1280`）。
2. **与 Z8 `cmd10 TX[0x0B] = (n << 4)` ($A = 2^{n+7}$) 严格同构的光滑连续双向坐标变换**：
   - 挂载时按 `f_max` 选定单会话常数 $A = 2^{n+7}$（`<200mm: n=7, A=16384`；`200..399mm: n=9, A=65536`；`>=400mm: n=10, A=131072`，确保 `Sigma 150-600` 在 `600mm` 端 `H_Z = 46811` 脉冲高于物理步进分辨率 `2×` 以上，零远摄量化损失）；
   - 正向（由连续编码器 $S_{\text{E}}$ 经光滑凸轮/高斯反比函数 $\Phi_z(S_{\text{E}})$ 计算，严禁直接用粗分档 `ID05` 物距跳变）：
     $$C_{\text{Z}}(S_{\text{E}}, z) = \Phi_z(S_{\text{E}}) = \operatorname{round}\!\left(\frac{A}{D_{\text{m,smooth}}(S_{\text{E}}, z)}\right), \qquad C_{\text{Z}}\bigl(E_{\infty,\text{true}}(z), z\bigr) \equiv 0$$
     远端过冲区按无穷远首段斜率 $\sigma_0(z)$ 线性延拓（报机械下界 $L_{\text{Z}} = -512$），最近对焦端报机械上界 $H_{\text{Z}}(z) = \text{round}(A / D_{\text{mfd}}(z))$。当用户在 Z8 菜单 `a16` 设定任意 `0.1–999 m` 限位（含 `999m -> 995m`）时，Z8 算出的 $\lfloor A / D_{\text{lim}} \rfloor$ 与 `HOT[2..5]` 实时 `C_Z` 逐毫米重合！
   - 雅可比一致相位散焦灵敏度与逆向目标/速度解算：
     记局部单调斜率 $J(S_{\text{E}}, z) = \left|\frac{\partial \Phi_z(S_{\text{E}})}{\partial S_{\text{E}}}\right| > 0$：
     - `cmd20 Z_wire[0x6D..0x70]` 上报灵敏度：$K_{\text{Z}} = J(S_{\text{E}}, z) \cdot K_{\text{E}}(S_{\text{E}}, z)$；
     - 收到 Z8 目标脉冲 $C_{\text{Z}}^*$（先钳位于 `[L_Z, H_Z]`）与脉冲速率 $V_{C,\text{pps}}$ 后，逆解 E 口目标与速率：
       $$S_{\text{E}}^* = \operatorname{clamp}\!\left(\Phi_z^{-1}(C_{\text{Z}}^*),\; E_{\text{lim,min}},\; E_{\text{lim,max}}\right), \qquad V_{S,\text{pps}} = \frac{V_{C,\text{pps}}}{J(S_{\text{E}}, z)}$$

### 6.2 Z8 速度解码与三类执行器混合控制律
1. **Z8 速度字 `(lo, hi)` 解码**：`lo == 0xFF && hi == 0x3F` 为不限速（取镜头当前温区上限 $V_{\max}$）；否则符号 `dir_z = (hi & 1) ? -1 : +1`，幅值 $V_{C,\text{pps}} = \frac{(256 + \text{lo}) \cdot 2^{\text{hi}\gg 1}}{512}$（`E4 00` 严格取 `payload[5..6]` 为主速度、`payload[7..8]` 为副速度、`s32_le(payload[11..14])` 为第二预测终点并执行 `s32` 钳位）。
2. **三类镜头驱动路由**：
   - **Class A（Sony 扩展族 `43 / 49`）**：不限速 `C0 00` 发 `0x43 MoveFc2`；连续追踪 `E2 / E4 / E6` 及限速 `C0` 发 `0x49 MoveFcVel2`。
   - **Class B（旧 `F1 / F2` 族）**：全无符号 `u16` 处理 `0x8000..0xFFFF` 高位区间同帧下发目标与步长。
   - **Class C（Sigma / Tamron / Samyang / Batis `1D + 3C` 双区混合律）**：
     - 对 `Sigma 150-600` 按镜内温度传感器施加 8 档硬件速率包络（`>25°C: 44,800 ticks/s` 至 `<=-15°C: 25,600 ticks/s`）；对双浮动镜头（`Sigma 70-200/2.8`、`Tamron F072 90/2.8`、`AA056 70-180 G1`）在近摄高倍率区（$\beta > 0.25$）下调巡航上限 `20%` 并将精细捕获区放宽至 `±40` ticks；
     - 全速 `C0 00` 跳焦与终端捕获窗（`1 < |e| <= step_per_vd`）发绝对模式 `1D = [0x1D, T_lo, T_hi, 0x00, 0x00]`；
     - 连续追焦与视频平滑拉焦发 `3C`，每帧递增翻转 `byte1[3:2] = (++g_seq3c) & 3`；适马用 `mode 0` 原始速率（配合 `ID1F mode=8` 解锁无缝同向调速），腾龙用 `mode 1` 乘 `16 / TX06[4..5]`；
     - `E0 00 / E1 00` 停止命令**唯一映射为 `0x1C`**（严禁发 `3C M=0`）；`E8 00` 微摆经 $1/J$ 折算后由 `0x49` / `3C` 执行。

### 7.2 `cmd50 / cmd51` 跨品牌关机异步机械驻车三步曲
收到 Z 机身 `cmd50 00` 后：
1. 立即停发 `SPI1` 热线，回 `55 00 00 AB`，置状态机 `PARK_SEND_ID04`；
2. 依次向 E 口发送：
   - **Step A**：`ID04`（置 `wire[16] = 0x04` 驻车预告位）；
   - **Step B**：**全零掩码 `ID0A`（`0A` + 16 个 `0x00`）**——停止镜头周期 `ID05/ID06` 上报，并**将腾龙镜头 `session_mode` 由 `1` 切回 `2`**（满足腾龙 `RX16` `0x08051558` 的硬门控！）；
   - **Step C**：`ID16 = [0x16, 0x01]`（驱动适马 OS2 执行 `'^' 0x5E` 机械锁止及腾龙/索尼镜组驻车）；
3. 等待镜头回传 `ID16` 应答（上限 `35 ms` 超时保护）期间，对 `cmd51 00` 返回 `55 41 00 6A`（Busy）；收到 `ID16` 应答或满 `35 ms` 后返回 `55 01 00 AA`（Ready），安全放行机身断电。

## 8. 核心业务域三：EXIF 对焦距离全链路闭合、零误差光圈与控件同步（`aperture_controls.c`）

### 8.1 Nikon Z `LensData 0802` (`108B`) 对焦距离四字段协同与快照锁存契约
1. **四字段字节级联动**：
   - `LensData + 0x30..0x31` $\leftarrow$ `cmd10 TX[0x01..0x02]` (`prop 3` 主 `LensID != 0`)；
   - `LensData + 0x35` $\leftarrow$ `cmd10 TX[0x06]` (`prop 5` 最高字节)：恒填 **`0x01`**；
   - `LensData + 0x4E..0x4F` $\leftarrow$ `cmd20/00 Z_wire[0x2F..0x30]` (`prop 0x117`)：
     $$\text{code}_{0x117}(x) = \begin{cases} \text{0xFFFF}, & x = \text{0xFFFF}\text{（无穷远）} \\ \operatorname{clamp}(2048 + 48 \cdot x,\; \text{0x0008},\; \text{0xFFF7}), & 0 \le x < \text{0xFFFF}\text{（有限物距）} \end{cases}$$
   - `LensData + 0x58` $\leftarrow$ `cmd20/00 Z_wire[0xBB]` (`prop 0xF8` 低字节)：`x == 0xFFFF` 时填 **`0x00`**（格式化呈现 `Inf`），`x < 0xFFFF` 时填 **`k_step ∈ [1, 36]`**（格式化呈现精确米值）。
2. **曝光快照锁存一致性（`ETZ-R019`）**：机身在快门释放 `getter` 处原子采样最新完成注册的 `cmd20/00` 快照写入独立照片 `metadata`，转接环通过双缓冲整帧原子切换发布 `cmd20/00` 与 `cmd20/01`，无需任何快门冻结特判。

### 8.2 `1/192 EV` 零往返误差光圈换算与物理光圈环双模态
1. **零往返误差双向定点数换算**（遍历 `C ∈ [0x0180, 0x0A80]` 全 `2,305` 码往返误差 `== 0`）：
   - Z 码 `C`（`F1.0 = 0x0180`，**`1 EV = 0x00C0 = 192`**）$\to$ E 线码 `P`（`F1.0 = 0x1000`，`1 EV = 0x0100 = 256`）：
     $$C_{\text{clamped}} = \operatorname{clamp}_{s32}\bigl((int32\_t)\text{base} + \text{signed\_delta},\; C_{\text{open}},\; C_{\text{min}}\bigr), \qquad P = \left\lfloor\frac{4 \cdot C_{\text{clamped}} + 1}{3}\right\rfloor + \text{0x0E00}$$
   - E 线码 `P` $\to$ Z 码 `C`：
     $$C(P) = \text{0x0180} + \bigl((P \gg 8) - \text{0x10}\bigr) \cdot \text{0xC0} + \bigl(((P \mathbin{\&} \text{0xFF}) \cdot \text{0xC0} + 128) \gg 8\bigr)$$
2. **物理光圈环零冲突双模态**（读取解包槽 `g_id05.grp[4]`）：
   - **`'A'` 档（`grp[4][2].bit0 == 0`）**：`base = C_open(f)`，`cur_delta = max(0, C_cur - base)`，`max_delta = C_min(f) - C_open(f)`，机身拨盘目标写入 `ID03 wire[9..10]`，`wire[13] = 0x18`；对 `TX07[6] == 1` 的 6 款老腾龙追加 `2F 09 0A` 发 32B，其余全系严格发 **29B `ID03`**；
   - **手动光圈环档（`grp[4][2].bit0 == 1`）**：取 `P_ring = u16_le(grp[4][0..1])` 闭环写入 `ID03`，同时在 `cmd20/00` 报 **`base = C(P_ring)`、`cur_delta = 0`、`max_delta = 0`**，使机身实时同步环上 F 值测光与记录 EXIF。

## 10. 零拆机飞行记录仪（`0x7A000`）与双扇区原子日志（`0x7C000/0x7E000`）

### 10.1 `SRAMH` 安全 `EFM` 驱动铁律（`efm_ramfunc.c`）
1. 解锁前先检查 `(EFM->FAPRT & 1) == 0`，仅在锁止态依次写 `0x0123`、`0x3210`；
2. 保存 `FRMC` 原值，**清除 `FRMC.CACHE (bit16) = 0`**，置 **`FWMC.PEMODE (bit0) = 1`**；
3. **4B 单字编程**（用于 `0x7A000` `BLACKBOX_LOG`，耗时 `~45 µs`）：设 `FWMC.PEMOD = 1` (`0x10`)，写 32-bit 目标字，轮询 `FSR.RDY (bit8) == 1`，写 `FSCLR = 0x3F` 清标志，恢复 `FWMC = 0`、`FRMC.CACHE = 1`，写 `FAPRT = 0` 上锁（因全部 4 个硬件 ISR 均驻留 `SRAMH .ramfunc`，无需关全局中断）；
4. **8 KiB 扇区擦除**（用于 `0x7C000 / 0x7E000` 乒乓日志切换，耗时 `16–20 ms`）：**严格限制在 `cmd50` 关机停热线后或拔镜空闲态执行**，严禁在活跃拍摄/对焦周期触发。

### 10.2 `0x7A000`（`LBA 858..873`）32B 黑匣子记录结构与 `0x7C000/0x7E000` 128B 原子日志
- `bb_record_t`（`32B`）：`{uint32_t magic_tag; uint32_t ts_us; uint16_t event_code; uint16_t lens_id; uint32_t arg0; uint32_t arg1; uint32_t arg2; uint32_t crc32;}`，实机测试后插 USB 升级座冷复位进 BL MSC，通过 `LBA 858..873` 直接读出完整微秒级时间线（注意：大镜像写入后若需校验安装载荷，须经 MCU 复位重进 USB 以恢复 BL `LBA 10` 读基准）。
- `journal_record_t`（`128B`）：先写前 `124B`（含 `CRC32`）并读回比对，最后单独写末 `4B commit_mark = 0x434F4D54`。
